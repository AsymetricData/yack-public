Four command-line programs in Yack

ls -al, cat, wc and a small TUI demo, each shown as the whole file: imports, helpers and main. Nothing is left out, and none of them needs a runtime or an argument-parser crate; memory is managed by the generated code.

Step 01

Create a project

A CLI is an ordinary Yack project: a folder with yack.toml, one dependency on lib/yack, and a main function. Every file below is copied verbatim from examples/cli and compiled on each commit.

terminal 
# from a checkout of the yack repository
make
./yack new mycli
cd mycli
../yack run
yack.toml 
[package]
name = "cli-demo"
version = "0.1.0"

[dependencies]
yack = { path = "../lib/yack" }

Each program is one file under examples/cli/src. Copy it into mycli/src/main.yack and ../yack run works: there is no generated code and no hidden module.

Step 02

A complete ls

main reads argv with os.command_args (), parses it with args.parse, then hands the parsed value to dispatch. -a and -l combine into the cluster -al, and the accessors return a pair so the rest of the parsed arguments stays available.

The long format asks io.read_file for the bytes and uses the string length as the size. A missing path writes on stderr, is counted, and finish exits with status 1. --help exits 0, no path exits 2.

ls.yack 
import yack/args
import yack/cli
import yack/io
import yack/os
import yack/sort
import yack/string

(* ls: a tiny `ls` built on the standard library.

   The kernel exposes no `readdir`/`stat` yet, so this variant lists the paths
   named on the command line instead of walking a directory.  `-l` reports the
   size it gets by reading the file, and `-a` is accepted for `ls`
   compatibility. *)

fun specs () : args.spec list =
    [
        args.Flag (("all", Some ("a"), "show hidden entries (no effect yet)")),
        args.Flag (("long", Some ("l"), "long format: size and name")),
        args.Flag (("help", Some ("h"), "show this help")),
        args.Positional (("path", "file or directory", false))
    ]

(* Formate une ligne de sortie.
   - `long` : vrai pour préfixer la taille.
   - `name` : nom emprunté pour la ligne.
   - `contents` : contenu emprunté, source de la taille. *)
fun line_of (long : bool, name : borrow string, contents : borrow string) : string =
    if long then
        let val size = int_to_string (string.length (contents))
        in string.pad_left (borrow size, 8, 32) ^ "  " ^ string.copy (name)
        end
    else
        string.copy (name)

(* Écrit la ligne d'un chemin. Retourne faux si la lecture échoue.
   - `long` : format long demandé.
   - `path` : chemin consommé par la lecture. *)
fun print_one (long : bool, path : string) : bool =
    let val name = string.copy (borrow path)
    in
        case io.read_file (path) of
            Ok (contents) =>
                let val line = line_of (long, borrow name, borrow contents)
                    val _ = io.print_line (borrow line)
                in true
                end
          | Error (message) =>
                let val line = "ls: " ^ name ^ ": " ^ message
                    val _ = io.eprint_line (borrow line)
                in false
                end
    end

(* Écrit chaque chemin et compte les échecs.
   - `long` : format long demandé.
   - `paths` : liste Affine consommée dans l'ordre. *)
fun print_paths (long : bool, paths : string list) : int =
    case paths of
        Nil => 0
      | Cons (path, rest) =>
            let val ok = print_one (long, path)
                val failures = print_paths (long, rest)
            in if ok then failures else failures + 1
            end

(* Termine avec le code d'échec s'il y a eu au moins une erreur.
   - `failures` : nombre de chemins illisibles. *)
fun finish (failures : int) : unit =
    if failures = 0 then () else os.exit (cli.exit_failure ())

(* Affiche l'aide puis termine avec le code 0. *)
fun print_help () : unit =
    let val _ = cli.print_help ("ls", "List file information.", specs ())
    in os.exit (cli.exit_ok ())
    end

(* Signale l'absence de chemin puis termine avec le code d'usage. *)
fun no_path () : unit =
    let val _ = cli.print_error ("no path given: readdir is not available yet")
    in os.exit (cli.exit_usage ())
    end

(* Trie les chemins avant de les lister.
   - `long` : format long demandé.
   - `paths` : positionnels consommés. *)
fun list_paths (long : bool, paths : string list) : unit =
    case paths of
        Nil => no_path ()
      | Cons (path, rest) =>
            finish
                (print_paths
                     (long, sort.sort_string_list (Cons ((path, rest)))))

(* Consomme les options puis transmet les chemins au rendu.
   - `value` : `parsed` consommé par les accesseurs. *)
fun dispatch (value : args.parsed) : unit =
    let val helpPair = args.take_flag (value, "help")
        val longPair = args.take_flag (helpPair.1, "long")
    in
        if helpPair.0 then print_help ()
        else list_paths (longPair.0, args.positionals (longPair.1))
    end

fun main () =
    case args.parse (specs (), os.command_args ()) of
        Error (message) =>
            let val _ = cli.print_error (message)
            in os.exit (cli.exit_usage ())
            end
      | Ok (value) => dispatch (value)

What this ls cannot do yet. The example predates the directory modules, so it lists the paths you name instead of walking a directory, and -a is accepted but changes nothing. Directories read as empty. yack/fs now provides list_dir and stat, so a later version can report real metadata; the missing pieces are tracked in the standard library plan ↗.
Step 03

A complete cat

cat is the smallest of the four programs: a result from io.read_file, raw output through io.print_raw, and error lines on stderr. One function handles a file, the recursive copy_paths threads the list, and finish turns the failure count into an exit status. With no argument it reads stdin.

cat.yack 
import yack/args
import yack/cli
import yack/io
import yack/os
import yack/string

(* cat: copy files, or stdin, to stdout.

   Shows the two halves of a CLI: a `result` from `io.read_file`, and error
   lines on stderr with a non-zero exit status. *)

fun specs () : args.spec list =
    [
        args.Flag (("help", Some ("h"), "show this help")),
        args.Positional (("file", "file to print", false))
    ]

(* Termine avec le code d'échec s'il y a eu au moins une erreur.
   - `failures` : nombre de fichiers illisibles. *)
fun finish (failures : int) : unit =
    if failures = 0 then () else os.exit (cli.exit_failure ())

(* Écrit un fichier sur stdout. Retourne le nombre d'échecs.
   - `path` : chemin consommé par la lecture. *)
fun copy_one (path : string) : int =
    let val name = string.copy (borrow path)
    in
        case io.read_file (path) of
            Ok (contents) =>
                let val _ = io.print_raw (borrow contents)
                in 0
                end
          | Error (message) =>
                let val line = "cat: " ^ name ^ ": " ^ message
                    val _ = io.eprint_line (borrow line)
                in 1
                end
    end

(* Copie chaque fichier de la liste.
   - `paths` : liste Affine consommée dans l'ordre. *)
fun copy_paths (paths : string list) : int =
    case paths of
        Nil => 0
      | Cons (path, rest) => copy_one (path) + copy_paths (rest)

(* Copie stdin quand aucun fichier n'est nommé. *)
fun copy_stdin () : unit =
    case io.read_stdin () of
        Error (message) =>
            let val _ = cli.print_error (message)
            in os.exit (cli.exit_failure ())
            end
      | Ok (contents) =>
            let val _ = io.print_raw (borrow contents)
            in ()
            end

(* Choisit stdin ou les fichiers nommés.
   - `paths` : positionnels consommés. *)
fun copy_all (paths : string list) : unit =
    case paths of
        Nil => copy_stdin ()
      | Cons (path, rest) =>
            finish (copy_one (path) + copy_paths (rest))

(* Affiche l'aide puis termine avec le code 0. *)
fun print_help () : unit =
    let val _ = cli.print_help ("cat", "Copy files to standard output.", specs ())
    in os.exit (cli.exit_ok ())
    end

(* Consomme les options puis lance la copie.
   - `value` : `parsed` consommé par les accesseurs. *)
fun dispatch (value : args.parsed) : unit =
    let val helpPair = args.take_flag (value, "help")
        val paths = args.positionals (helpPair.1)
    in
        if helpPair.0 then print_help () else copy_all (paths)
    end

fun main () =
    case args.parse (specs (), os.command_args ()) of
        Error (message) =>
            let val _ = cli.print_error (message)
            in os.exit (cli.exit_usage ())
            end
      | Ok (value) => dispatch (value)

copy_one copies the name before passing the path to io.read_file: reading consumes the path, so the error message needs its own owner. The compiler would reject the other order.

Step 04

A complete wc

wc counts from a borrowed string: count_lines checks the last byte, count_words_from walks the bytes once, and string.length gives the byte count. report pads the three columns and adds the name, so files and stdin print the same format.

wc.yack 
import yack/args
import yack/cli
import yack/io
import yack/os
import yack/string

(* wc: count lines, words and bytes.

   Words are separated by ASCII whitespace (space, tab, newline, carriage
   return, vertical tab, form feed).  Without a file argument `wc` reads
   stdin, like the real one. *)

fun specs () : args.spec list =
    [
        args.Flag (("help", Some ("h"), "show this help")),
        args.Positional (("file", "file to count", false))
    ]

(* Compte les lignes d'un texte emprunté, dernière ligne partielle incluse. *)
fun count_lines (contents : borrow string) : int =
    let val size = string.length (contents)
        val breaks = string.count (contents, borrow "\n")
    in
        if size = 0 then 0
        else if string.char_at_unchecked (contents, size - 1) = 10 then breaks
        else breaks + 1
    end

(* Reconnaît les séparateurs de mots que `wc` compte.
   - `code` : code d'octet à tester.

   Retourne vrai pour espace, tabulation, saut de ligne, retour chariot,
   tabulation verticale et saut de page. *)
fun is_word_space (code : int) : bool =
    if code = 32 then true
    else if code = 9 then true
    else if code = 10 then true
    else if code = 13 then true
    else if code = 11 then true
    else code = 12

(* Parcourt le texte et compte les débuts de mots.
   - `contents` : texte emprunté, indexé en octets.
   - `index` : position courante.
   - `size` : borne exclusive.
   - `inside` : vrai si le parcours est dans un mot.
   - `total` : mots déjà comptés. *)
fun count_words_from
        (contents : borrow string, index : int, size : int, inside : bool,
         total : int) : int =
    if index >= size then
        total
    else
        let val space =
                is_word_space (string.char_at_unchecked (contents, index))
        in
            if space then
                count_words_from (contents, index + 1, size, false, total)
            else if inside then
                count_words_from (contents, index + 1, size, true, total)
            else
                count_words_from (contents, index + 1, size, true, total + 1)
        end

(* Compte les mots séparés par n'importe quel espace ASCII. *)
fun count_words (contents : borrow string) : int =
    count_words_from (contents, 0, string.length (contents), false, 0)

(* Aligne un entier sur sept colonnes. *)
fun column (value : int) : string =
    let val text = int_to_string (value)
    in string.pad_left (borrow text, 7, 32)
    end

(* Construit la ligne `lines words bytes name`.
   - `name` : nom affiché, emprunté.
   - `contents` : contenu emprunté, source des compteurs. *)
fun report (name : borrow string, contents : borrow string) : string =
    column (count_lines (contents)) ^
    column (count_words (contents)) ^
    column (string.length (contents)) ^
    " " ^ string.copy (name)

(* Termine avec le code d'échec s'il y a eu au moins une erreur.
   - `failures` : nombre de fichiers illisibles. *)
fun finish (failures : int) : unit =
    if failures = 0 then () else os.exit (cli.exit_failure ())

(* Compte un fichier et écrit sa ligne. Retourne le nombre d'échecs.
   - `path` : chemin consommé par la lecture. *)
fun count_one (path : string) : int =
    let val name = string.copy (borrow path)
    in
        case io.read_file (path) of
            Ok (contents) =>
                let val line = report (borrow name, borrow contents)
                    val _ = io.print_line (borrow line)
                in 0
                end
          | Error (message) =>
                let val line = "wc: " ^ name ^ ": " ^ message
                    val _ = io.eprint_line (borrow line)
                in 1
                end
    end

(* Compte chaque fichier de la liste.
   - `paths` : liste Affine consommée dans l'ordre. *)
fun count_paths (paths : string list) : int =
    case paths of
        Nil => 0
      | Cons (path, rest) => count_one (path) + count_paths (rest)

(* Compte l'entrée standard quand aucun fichier n'est nommé. *)
fun count_stdin () : unit =
    case io.read_stdin () of
        Error (message) =>
            let val _ = cli.print_error (message)
            in os.exit (cli.exit_failure ())
            end
      | Ok (contents) =>
            let val line = report (borrow "-", borrow contents)
                val _ = io.print_line (borrow line)
            in ()
            end

(* Choisit stdin ou les fichiers nommés.
   - `paths` : positionnels consommés. *)
fun count_all (paths : string list) : unit =
    case paths of
        Nil => count_stdin ()
      | Cons (path, rest) =>
            finish (count_one (path) + count_paths (rest))

(* Affiche l'aide puis termine avec le code 0. *)
fun print_help () : unit =
    let val _ = cli.print_help ("wc", "Count lines, words and bytes.", specs ())
    in os.exit (cli.exit_ok ())
    end

(* Consomme les options puis lance le comptage.
   - `value` : `parsed` consommé par les accesseurs. *)
fun dispatch (value : args.parsed) : unit =
    let val helpPair = args.take_flag (value, "help")
        val paths = args.positionals (helpPair.1)
    in
        if helpPair.0 then print_help () else count_all (paths)
    end

fun main () =
    case args.parse (specs (), os.command_args ()) of
        Error (message) =>
            let val _ = cli.print_error (message)
            in os.exit (cli.exit_usage ())
            end
      | Ok (value) => dispatch (value)

No global counters. count_all sums the failures of count_one and count_paths; finish maps that number to the exit code. The counters never touch a global, so two instances in one process would not interfere.
Step 05

Colour and boxes

The last program combines yack/args, yack/ansi and yack/tui. ANSI helpers return strings; the TUI builds a box, a progress bar, a menu and a status line from those strings. Rendering is a value, so the same code runs in a terminal or in a test.

main.yack 
import yack/args
import yack/ansi
import yack/cli
import yack/io
import yack/os
import yack/string
import yack/tui

fun flag_help () : args.spec =
    args.Flag (("help", Some ("h"), "show this help"))

fun flag_verbose () : args.spec =
    args.Flag (("verbose", Some ("v"), "verbose output"))

fun opt_output () : args.spec =
    args.Opt (("output", Some ("o"), "output file", None))

fun pos_file () : args.spec =
    args.Positional (("file", "input file", true))

fun specs () : args.spec list =
    [
        flag_help (),
        flag_verbose (),
        opt_output (),
        pos_file ()
    ]

fun main () =
    let val argv = os.command_args ()
        val parsed = args.parse (specs (), argv)
    in
        case parsed of
            Error (message) =>
                let val _ = cli.print_error (message)
                in os.exit_usage ()
                end
          | Ok (value0) =>
                let val helpPair = args.take_flag (value0, "help")
                    val help = helpPair.0
                    val value1 = helpPair.1
                in
                    if help then
                        let val _ =
                                cli.print_help
                                    ("cli-demo", "A tiny Yack CLI.", specs ())
                        in os.exit_ok ()
                        end
                    else
                        let val verbosePair = args.take_flag (value1, "verbose")
                            val verboseFlag = verbosePair.0
                            val value2 = verbosePair.1
                            val outputPair =
                                args.take_option_or (value2, "output", "stdout")
                            val output = outputPair.0
                            val value3 = outputPair.1
                            val files = args.positionals (value3)
                            val verbose = if verboseFlag then "yes" else "no"
                            val fileList = string.join (", ", files)
                            val body =
                                tui.kv ("verbose", verbose) ^ "\n" ^
                                tui.kv ("output", output) ^ "\n" ^
                                tui.kv ("files", fileList)
                            val menuItems =
                                Cons (("one", Cons (("two", Cons (("three", Nil))))))
                            val header =
                                ansi.bold () ^ "cli-demo" ^ ansi.reset () ^
                                ansi.dim () ^ "  tiny yack cli" ^ ansi.reset () ^
                                "\n\n"
                            val _ = io.print_raw (borrow header)
                            val boxed = tui.box ("run", body, 60) ^ "\n\n"
                            val _ = io.print_raw (borrow boxed)
                            val progress =
                                ansi.fg_cyan () ^
                                tui.progress (2, 5, 32) ^
                                ansi.reset () ^ "\n\n"
                            val _ = io.print_raw (borrow progress)
                            val menu = tui.menu (menuItems, 1, 24) ^ "\n"
                            val _ = io.print_raw (borrow menu)
                            val status = tui.status_bar ("✓ done  ·  0.1.0", 60) ^ "\n"
                            val _ = io.print_raw (borrow status)
                        in os.exit_ok ()
                        end
                end
    end

  • --memory=stack allocates in regions released at once, a good fit for short-lived CLIs.
  • make test-cli builds all four programs and checks flags, sizes, stdin and exit codes.
Step 07

What is still missing

A real ls -al needs directory and metadata calls, which yack/fs provides now; the programs here predate it and still list named paths. A raw terminal is still missing.

NeedStatusWorkaround in these examples
readdiryack/fs (list_dir)name the paths on the command line
stat (mode, owner, date)partial: yack/fs (size, mtime, kind)size from io.read_file length
raw mode, read_linemissingrender a screen, read stdin when piped
spawn a processyack/process (run)one binary, no shelling out
clock, date formattingyack/timeno timestamps in output

The missing entry is a compiler primitive and will arrive with docs/stdlib.md and tests. The modules marked available are already in lib/yack/src.
