Step 01

Change of habits

Alpage is a small web framework written in Yack. If you have written a handler in Go, Express or Wisp, nothing here is exotic: routes, handlers, middlewares, JSON. Four things differ, and the compiler holds you to them.

GoTypeScriptGleamYack
MemoryGCGCGC (BEAM)ownership, frees placed at compile time
Errors(T, error)throwResult(a, e)'a result, Reply.fail
AbsencenilundefinedOption(a)'a option
Closuresyesyesyesno capture: handlers are top-level fun
Pipesnono|>|>, first argument
A value used twiceshared pointershared referenceimmutable, sharedmoved, or explicitly borrowed

The last row is the one to keep in mind. In Yack a request, a string or a list has one owner. Passing it to a function hands it over; the compiler frees it where the last owner is done. No GC pause, and nothing to write by hand.

Coming from Gleam? You will feel at home: immutable data, case, result, pipes. The new part is that a value is consumed when you pass it, unless you borrow it with &x (short for borrow x).
Step 02

A project

A project is a folder with a yack.toml. Dependencies are local paths for now: point them at the lib/ folder of your Yack checkout.

terminal 
# from a checkout of the yack repository
make
./yack new alpage_tutorial
cd alpage_tutorial
yack.toml 
[package]
name = "alpage_tutorial"
version = "0.1.0"

[dependencies]
alpage = { path = "../lib/alpage" }
web = { path = "../lib/web" }
http_server = { path = "../lib/http_server" }
net = { path = "../lib/net" }
yack = { path = "../lib/yack" }

The paths assume the project sits at the root of the checkout, next to the yack binary. The tutorial uses three files: src/Api.yack (handlers and the app), src/main.yack (the server) and src/test.yack (in-memory tests). The finished project is examples/alpage_tutorial in the repository; every snippet on this page is copied from it and tested on each commit.

Step 03

First handler

A handler takes a context and the request, and returns a reply.

func home(w http.ResponseWriter, r *http.Request) {
    fmt.Fprint(w, "hello from alpage")
}
app.get("/", (req, res) => {
  res.send("hello from alpage")
})
fn home(_req: Request) -> Response {
  wisp.ok() |> wisp.string_body("hello from alpage")
}
fun home (ctx : Ctx.t, request : consume Request.t) : Reply.t =
    Reply.ok (Response.text ("hello from alpage"))
  • Ctx.t is Copy: a small value (the request id) you can use freely.
  • consume Request.t says the handler owns the request. When it returns, the request is freed. You did not use it here, that is fine: an unused owned value is dropped, not leaked.
  • Reply.t is a success (Reply.ok response) or an application error (Reply.fail error). No exceptions.
No ResponseWriter. Go writes into w as a side effect; Express mutates res. In Yack the response is a value you return, like in Wisp.
Step 04

Query string and ownership

Request.query returns an option. Unwrap it with option.unwrap_or, or match on it like a Gleam Option.

src/Api.yack 
fun hello (ctx : Ctx.t, request : consume Request.t) : Reply.t =
    let val name = Request.query (&request, "name") |> option.unwrap_or ("stranger")
    in Reply.ok (Response.text ("hello, " ^ name)) end

^ concatenates strings. It consumes both sides, so when the left one is not needed anymore the compiler grows it in place instead of copying.

The mistake every newcomer makes

Read two parameters the way you would in Go, without borrowing:

traps/request_twice.yack 
fun greet (ctx : Ctx.t, request : consume Request.t) : Reply.t =
    let val first = Request.query (request, "first")
        val last = Request.query (request, "last")
    in
        Reply.ok (Response.text ("hello"))
    end
yack check 
error[E3004]: type mismatch in argument 1 of `Request.query`
  --> traps/request_twice.yack:9:21
   |
 9 |     let val first = Request.query (request, "first")
   |                     ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
   = note: expected: borrow Request.t
   = note: found: consume Request.t
   = hint: make the intended type explicit with a type annotation, or convert the value

Request.query borrows the request: it reads the value without consuming it. The handler keeps ownership, so the request is still available afterwards and freed exactly once at the end.

The fix is to take one borrow and reuse it: &request is the short form of borrow request.

src/Api.yack 
fun greet (ctx : Ctx.t, request : consume Request.t) : Reply.t =
    let val req = &request
        val first = Request.query (req, "first") |> option.unwrap_or ("")
        val last = Request.query (req, "last") |> option.unwrap_or ("")
    in
        Reply.ok (Response.text ("hello, " ^ first ^ " " ^ last))
    end
Why val req = &request? A shared borrow is Copy, so it can be passed twice. NLL ends the loan at its last use, then the handler still owns the request. No tuple, no *_keep variant: the borrow is the whole trick.
Step 05

Path parameters, without closures

Routes take :name segments. An extractor parses the segment and calls your function with a typed value, or answers 400 on its own. 

func square(w http.ResponseWriter, r *http.Request) {
    n, err := strconv.Atoi(r.PathValue("n"))
    if err != nil {
        http.Error(w, "invalid path parameter", 400)
        return
    }
    fmt.Fprintf(w, `{"square":%d}`, n*n)
}
app.get("/square/:n", (req, res) => {
  const n = Number.parseInt(req.params.n, 10)
  if (Number.isNaN(n)) return res.status(400).send("invalid path parameter")
  res.json({ square: n * n })
})
fn square(n: String) -> Response {
  case int.parse(n) {
    Ok(n) -> json_response(n * n)
    Error(Nil) -> wisp.bad_request()
  }
}
fun square_of (ctx : Ctx.t, n : int) : Reply.t =
    Reply.ok (Response.json ("{\"square\":" ^ int_to_string (n * n) ^ "}"))

fun square (ctx : Ctx.t, request : consume Request.t) : Reply.t =
    Extract.path_int (ctx, request, "n", square_of)

square_of is a plain top-level function passed by name. Yack has no capturing closures, so a callback cannot close over local variables: everything it needs arrives as an argument. That is what keeps ownership checkable without a GC: a closure would be a hidden second owner.

Coming from TypeScript? (req, res) => ... inline everywhere is not possible. Write a named fun; the type of a parameter like (Ctx.t, int) -> Reply.t tells you exactly which arguments it gets.
Step 06

JSON body, errors as values

Extract.json reads the body, runs your decoder, and on success calls the next function with the decoded value. A decoder is a function from the borrowed body to a result.

src/Api.yack 
fun decode_items (body : &string) : int list result =
    case Decode.parse (body) of
        Error message => Error (message)
      | Ok value =>
            (case json.as_object (value) of
                 Error message => Error (message)
               | Ok fields =>
                     json.field_decode (&"items", Decode.int_list, fields))

fun add (pair : int * int) : int = pair.0 + pair.1

fun sum_items (ctx : Ctx.t, items : consume int list) : Reply.t =
    case items of
        Nil => Reply.fail (AppError.unprocessable ("items must not be empty"))
      | Cons (first, rest) =>
            let val total = list.foldl (add, first, rest)
            in Reply.ok (Response.json ("{\"sum\":" ^ int_to_string (total) ^ "}"))
            end

fun sum (ctx : Ctx.t, request : consume Request.t) : Reply.t =
    Extract.json (ctx, request, decode_items, sum_items)
  • A body that is not valid JSON never reaches sum_items: the extractor answers 400 invalid JSON body.
  • An empty list is a business error: Reply.fail (AppError.unprocessable ...) becomes 422 in one central place.
  • list.foldl takes add by name, again no closure.
AppErrorStatusTypical use
bad_request msg400malformed input
unprocessable msg422valid shape, invalid content
not_found ()404missing resource (also unknown routes)
conflict msg409state conflict
unavailable msg503dependency down
internal msg500bug or invariant broken
Step 07

The application is a value

Routes and middlewares are added with a pipeline, Gleam style. The result is an ordinary value: the server runs it, and so do the tests.

src/Api.yack 
fun application () : Alpage.t =
    Alpage.new ()
    |> Alpage.get ("/", home)
    |> Alpage.get ("/hello", hello)
    |> Alpage.get ("/greet", greet)
    |> Alpage.get ("/square/:n", square)
    |> Alpage.post ("/sum", sum)
    |> Alpage.get ("/admin", admin)
    |> Alpage.with (Alpage.log ())
    |> Alpage.with (Middleware.before (require_token))
    |> Alpage.with (Middleware.security_headers ())
src/main.yack 
import Api
import alpage/Alpage
import yack/io

fun main () =
    case Alpage.run (Api.application (), Alpage.config (18093)) of
        Ok _ => ()
      | Error message => io.print_line (borrow message)
terminal 
../yack run
# another terminal
curl localhost:18093/hello?name=Ada
curl -X POST -d '{"items":[4,5]}' localhost:18093/sum
curl -H 'X-Token: secret' localhost:18093/admin

Alpage.run returns a unit result: a failure to bind the port is a value too, printed by main. A GET on /sum answers 405 method not allowed, an unknown path 404.

Step 08

Middleware

A before middleware receives the request and returns it, with an optional early reply. Returning Some reply stops the chain. 

func requireToken(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        if strings.HasPrefix(r.URL.Path, "/admin") &&
            r.Header.Get("X-Token") != "secret" {
            http.Error(w, "unauthorized", 401)
            return
        }
        next.ServeHTTP(w, r) // a closure over `next`
    })
}
app.use((req, res, next) => {
  if (req.path.startsWith("/admin") && req.get("X-Token") !== "secret") {
    return res.status(401).send("unauthorized")
  }
  next()
})
fn require_token(req: Request, next: fn() -> Response) -> Response {
  case request.get_header(req, "x-token") {
    Ok("secret") -> next()
    _ -> wisp.response(401) |> wisp.string_body("unauthorized")
  }
}
fun denied () : Reply.t =
    Reply.ok (Response.with_status (Response.text ("unauthorized"), 401))

fun token_ok (token : string option) : bool =
    case token of
        Some value => string_eq (&value, &"secret")
      | None => false

fun require_token (ctx : Ctx.t, request : Request.t) : Request.t * Reply.t option =
    let val path = Request.path (&request)
    in
        if string.starts_with (&path, &"/admin") then
            let val token = Request.header (&request, "X-Token")
            in
                if token_ok (token) then (request, None)
                else (request, Some (denied ()))
            end
        else (request, None)
    end
  • The middleware owns the request while it runs, reads it through borrows, and gives the same request back. Nothing is copied and no tuple is threaded.
  • Layers run in the order of Alpage.with. A refused request is still logged (the log layer comes first) and still gets the security headers (their after hook wraps the reply on the way out).
  • There is no next callback: the chain is data, so no closure is needed.
Step 09

Testing without a socket

alpage/Test runs the same router, middlewares and error mapping as the server; only the transport is gone. Like httptest in Go or supertest in Node, minus the port.

src/test.yack 
fun expect (client : Test.client, label : string, raw : string,
            want_status : int, want_body : string) : Test.client =
    let val result = Test.request (client, Request.parse (raw))
        val client = result.1
        val _ =
            case result.0 of
                { status = got, headers = _headers, body = text } =>
                    if got = want_status then
                        if string_eq (borrow text, borrow want_body) then say ("ok " ^ label)
                        else say ("FAIL " ^ label ^ ": body " ^ text)
                    else say ("FAIL " ^ label ^ ": status " ^ int_to_string (got))
    in
        client
    end

fun get (path : string) : string =
    "GET " ^ path ^ " HTTP/1.1\r\nHost: localhost\r\n\r\n"

fun main () =
    case Test.start (Api.application (), Alpage.config (0)) of
        Error message => say (message)
      | Ok client =>
            client
            |> expect ("home", get ("/"), 200, "hello from alpage")
            |> expect ("hello query", get ("/hello?name=Ada"), 200, "hello, Ada")
            |> expect ("hello default", get ("/hello"), 200, "hello, stranger")
            |> expect ("greet", get ("/greet?first=Ada&last=Lovelace"), 200,
                       "hello, Ada Lovelace")
            |> expect ("square", get ("/square/12"), 200, "{\"square\":144}")
            |> expect ("square bad", get ("/square/abc"), 400, "invalid path parameter")
            |> expect ("sum",
                       "POST /sum HTTP/1.1\r\nHost: localhost\r\nContent-Length: 17\r\n\r\n{\"items\":[1,2,3]}",
                       200, "{\"sum\":6}")
            |> expect ("sum empty",
                       "POST /sum HTTP/1.1\r\nHost: localhost\r\nContent-Length: 12\r\n\r\n{\"items\":[]}",
                       422, "items must not be empty")
            |> expect ("sum bad json",
                       "POST /sum HTTP/1.1\r\nHost: localhost\r\nContent-Length: 5\r\n\r\n{oops",
                       400, "invalid JSON body")
            |> expect ("sum wrong method", get ("/sum"), 405, "method not allowed")
            |> expect ("admin denied", get ("/admin"), 401, "unauthorized")
            |> expect ("admin",
                       "GET /admin HTTP/1.1\r\nHost: localhost\r\nX-Token: secret\r\n\r\n",
                       200, "welcome, admin")
            |> expect ("missing", get ("/missing"), 404, "not found")
            |> Test.close
terminal 
../yack run src/test.yack
→ ok home … ok missing

The test client is Affine as well: each request consumes it and returns it, which is why the calls chain with |>. Forget to thread it and the compiler tells you, the same way as for the request.

Step 10

Check, build, run

terminal 
# type, ownership and the graph validator: silent when all is well
../yack check src/main.yack

# native binary, then the same server with region allocation, no malloc per request
../yack build src/main.yack server
../yack build --memory=stack --arena-reserve=64M src/main.yack server-stack

# what each arena block allocates and frees
../yack arena src/Api.yack
  • yack check runs the type checker, the ownership checker, then lowers the program and re-proves ownership on its control-flow graph. A program that would leak or double free does not build.
  • --memory=stack allocates per request in regions released at once: no malloc/free per string.
  • yack lsp gives the same diagnostics in your editor, plus inferred types and arena hints.
